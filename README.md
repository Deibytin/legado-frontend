# Legado Frontend

Frontend SaaS de Legado Sport con Next.js App Router, TypeScript, TailwindCSS, Axios, React Hook Form, Zod, Context API, i18n ES/EN y dark mode.

## Comandos

```bash
npm install
npm run dev
```

Abrir:

```text
http://localhost:3000/login
```
